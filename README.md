# fractrure-tests

Серии расчётов разрушения циркония с гидридами (решатель – CalculiX-форк из `ccx-arch2`).

## Концепция «рваный лист» (2026-10)

Гидрид моделируется не толстым диском, а мезомасштабным **пакетом – рваным листом**
по морфологии FIB-SEM (Zircaloy-4, табл. 3.1–3.3 диссертации): пакеты длиной
~40–100 мкм, толщиной 0.5–2 мкм, с волнистостью/зигзагом пластинок
(окружные ±19°, радиальные ±35° – сглаженная «колода карт»), рваным краем, надрывами,
дырами и пальцевыми ответвлениями.

| Параметр | Значение |
|---|---|
| Область | 150 × 150 × 75 мкм; x = TD (нагрузка), y = ND, z = RD |
| Гидрид | один слой призм по толщине (каждая = 3 C3D4), толщина 0.5–2 мкм, плавное поле, к краям утоняется |
| Сетка листа в плоскости | ~1.5 мкм |
| Матрица | C3D4, сгущение от 1.5 мкм у листов до 9 мкм (рост 0.35 на мкм) |
| Граница | UC6 на всей поверхности листа (как в серии дисков) |
| Объёмная доля | параметр, по умолчанию 1.1 % (как у дисков) |
| Fn | доля объёма радиальных пакетов |
| Края области | листы могут выходить на боковые грани, но не на торцы (захваты) |
| Пакеты | не касаются друг друга (зазор ≥ 4 мкм); ответвление – в ~1.2 мкм от своего листа |
| Нагружение | одноосное растяжение по x, как в серии дисков |

## Структура

- `gen/` – генератор: `sheets.py` (форма пакета), `prism.py` (слой призм),
  `pack.py` (размещение), `volume.py` (согласованная сетка матрицы, gmsh),
  `sections.py`, `view3d.py` (картинки), `make_geometry.py` (всё вместе).
- `geom/fn<P>/` – геометрия для согласования: `view3d.png`, сечения
  `sec_TD-ND.png`, `sec_ND-RD.png`, `sec_TD-RD.png`, `zoom.png`, `stats.json`, `mesh.npz`.

```
cd gen && ./make_geometry.py --seed 1 --fn 50 --out ../geom/fn50
```
Зависимости: python3, numpy, scipy, shapely, gmsh (4.15), pyvista, matplotlib, xvfb-run.

## Параметры масштаба (серия `*s`, 2026-10-01)

Базовые свойства серии дисков подобраны под образец 4 мм. На области 150 мкм их
длины разрушения больше самих элементов и пакетов: при базовых u_f матрица не
разрушается и к ε = 11 % (D_max = 0.04; расчёты `base_run_fn*` остановлены).
Прочности, упрочнение и локусы ε_f(η) оставлены базовыми; заменены только длины/энергии:

| параметр | база | серия `*s` | обоснование |
|---|---|---|---|
| u_f Zr | 0.015 мм | 0.001 мм | порядок расстояния между частицами/порами (слияние пор) |
| u_f ZrH | 0.004 мм | 0.00025 мм | K_IC δ-гидрида ≈ 3.3 МПа√м → G ≈ K²(1−ν²)/E ≈ 74 Дж/м², u_f = 2G/σ |
| G_c границы (затравка / прочие) | 2.0 / 2.4 Н/мм | 0.0625 / 0.075 Н/мм | граница не прочнее гидрида; δ_f = 2G_c/T_n0 ≈ 0.5 мкм |

```
./mkdeck.py ../geom/fn50 -o fn50s.inp --uf-zr 0.001 --uf-zrh 0.00025 --gc 0.0625 0.075
```
